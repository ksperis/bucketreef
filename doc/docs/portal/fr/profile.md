# Votre profil Portal

Ouvrez **Profil** depuis Portal pour modifier votre apparence, votre langue, vos
notifications et la sécurité de votre connexion tout en conservant le projet
Portal courant dans la navigation.

## Préférences personnelles

Vous pouvez modifier votre avatar, la langue, le thème et le workspace par
défaut. Si les notifications e-mail de quota sont disponibles pour votre compte,
vous pouvez également choisir de les recevoir ou non.

Selon votre préférence, votre image de profil peut provenir d'une image
importée, de votre identité liée ou de Gravatar. Choisissez les initiales si vous
ne souhaitez pas charger une image de profil externe.

## Sécurité de connexion

Utilisez **Sécurité** pour gérer les méthodes de connexion de votre propre
compte : mot de passe lorsque applicable, passkeys, codes de récupération,
sessions ouvertes et identités externes liées.

Si vous renouvelez les codes de récupération, les anciens codes cessent de
fonctionner et les sessions existantes sont déconnectées. Enregistrez les
nouveaux codes avant de quitter l'écran qui les affiche.

## Ce que le profil ne modifie pas

Votre profil ne change ni votre rôle dans le projet Portal ni vos permissions
sur un espace de stockage. Si un projet ou un espace est absent, consultez
[Dépannage](help/troubleshooting.md) ou [Demandes](help-requests.md).

Un rôle Portal Manager reste un rôle Portal et ne donne pas accès au workspace Manager.
