# Premiers pas

Portal est le workspace qui permet de travailler avec les projets de stockage
et les **espaces de stockage** qui vous sont attribués.

## Votre première visite

1. Ouvrez `/portal` et choisissez le projet auquel vous avez accès.
2. Ouvrez **Espaces**.
3. Choisissez un espace de stockage puis ouvrez **Fichiers**.
4. Si votre rôle le permet, importez un petit fichier de test puis téléchargez-le.
5. Ouvrez **Collaborateurs** pour savoir qui peut accéder à l'espace.
6. Consultez **État du stockage** pour vérifier la capacité ou les alertes.

Pour un usage normal de Portal, vous n'avez pas à choisir de compte S3,
d'endpoint ni d'identité d'exécution.

## Rôles Portal

- **Portal User** utilise les espaces et les actions qui lui sont autorisés.
- **Portal Manager** possède des responsabilités supplémentaires dans Portal.

Portal Manager ne signifie pas que vous avez accès au workspace Manager.
