# Cas d'usage de Portal

## Stocker les fichiers d'un projet

Ouvrez le projet, choisissez un espace de stockage puis utilisez sa vue
**Fichiers** pour importer, organiser, prévisualiser et télécharger le contenu.

## Travailler en équipe

Utilisez un espace partagé avec l'équipe ou avec des personnes sélectionnées et
gérez les collaborateurs selon votre rôle Portal. Lorsqu'une modification des
membres du projet doit être approuvée par un administrateur, Portal crée une
demande.

## Restaurer un ancien fichier

Lorsque l'historique est disponible, ouvrez les versions précédentes du fichier
et restaurez ou téléchargez la version souhaitée.

## Partager en dehors du projet

Si le projet autorise le partage externe, créez ou consultez les liens externes
depuis le fichier ou l'espace concerné. Les liens existants restent visibles afin
que les utilisateurs autorisés puissent les révoquer.

## Utiliser une autre application

Lorsque l'accès aux outils externes est activé, utilisez l'endpoint S3 et les
identifiants fournis par Portal pour configurer le client approuvé. Conservez le
secret dans ce client et ne le partagez pas avec les collaborateurs.

## Surveiller l'état du stockage

Utilisez **État du stockage** pour suivre la capacité et les alertes visibles par
votre projet. Si une limite doit être modifiée, utilisez le circuit de support ou
de demande prévu pour le projet.
