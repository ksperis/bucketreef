# Tâches courantes dans Portal

| Ce que vous voulez faire | Où aller |
|---|---|
| Ouvrir un espace de stockage | [Espaces](../spaces/index.md) |
| Importer, télécharger, prévisualiser, renommer, déplacer ou supprimer un fichier | [Fichiers](../files/index.md) |
| Restaurer ou consulter une ancienne version d'un fichier | [Versions précédentes](../files/versions.md) |
| Partager un espace avec des membres du projet | [Collaboration](../collaboration.md) |
| Vérifier ou révoquer des liens externes | [Collaboration](../collaboration.md) |
| Connecter un outil S3 externe | [Outils externes](../external-tools.md) |
| Vérifier la capacité ou les alertes d'utilisation | [État du stockage](../storage-health.md) |
| Consulter l'activité du projet | [Historique](../activity.md) |
| Demander une modification de membre ou une autre action administrative | [Demandes](../help-requests.md) |
| Modifier les préférences du projet qui vous sont déléguées | [Paramètres](../settings.md) |

Si une action est absente ou en lecture seule, commencez par
[Disponibilité des fonctions](../help/feature-availability.md).
