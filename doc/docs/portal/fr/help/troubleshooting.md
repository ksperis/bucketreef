# Dépannage de Portal

Utilisez cette page si vous ne trouvez pas un projet ou un espace de stockage,
si vous ne pouvez pas ouvrir des fichiers ou si une action Portal échoue.

## Vérifications à faire en premier

1. Vérifiez le projet sélectionné dans Portal.
2. Revenez dans **Espaces** et rouvrez l'espace de stockage.
3. Actualisez la page si quelqu'un vient de modifier vos droits.
4. Lisez le message associé à une action désactivée ou l'erreur affichée après un échec.
5. Si le problème persiste, ouvrez [Demandes](../help-requests.md) lorsque ce
   workflow est disponible, ou contactez votre administrateur.

## Problèmes courants

| Problème | Que vérifier |
|---|---|
| Portal ou un projet est absent | Vous devez être membre du projet Portal concerné. |
| Un espace de stockage est absent | Vérifiez que le bon projet est sélectionné et demandez au propriétaire ou au Portal Manager si vous devez avoir accès. |
| L'import ou la suppression n'est pas disponible | Votre rôle sur l'espace peut être en lecture seule, l'espace peut être archivé ou l'action peut être désactivée pour le projet. |
| Les versions précédentes sont absentes | L'espace peut ne pas conserver les versions ou vos droits peuvent ne pas autoriser l'historique. |
| Impossible d'inviter quelqu'un | Votre rôle Portal ou la délégation du projet peut imposer une demande au lieu d'une modification directe. |
| Un lien externe ou un accès pour outil externe est indisponible | L'administrateur du projet peut avoir désactivé cette fonction. |

Lorsque vous signalez un problème, indiquez le nom du projet, l'espace de
stockage, le fichier ou l'action, l'heure et le texte exact de l'erreur. Ne
transmettez jamais de clé secrète ni de mot de passe.
