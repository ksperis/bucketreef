# Disponibilité des fonctions

Utilisez cette page lorsqu'une fonction attendue dans **Portal** est absente,
désactivée ou en lecture seule.

## Ce qui détermine vos actions possibles

Portal s'adapte au projet sélectionné, à votre rôle dans ce projet et à votre
rôle sur chaque espace de stockage. Certaines fonctions peuvent aussi être
désactivées pour l'ensemble du projet par un administrateur.

| Ce qui manque | Vérification à faire en premier |
|---|---|
| Portal lui-même | Vérifiez que vous avez bien été ajouté au projet attendu. |
| Un espace de stockage | Vérifiez le projet sélectionné puis demandez au propriétaire ou à un Portal Manager si vous devez avoir accès à cet espace. |
| Créer ou modifier un espace | Ces actions dépendent de votre rôle Portal et de l'état actuel de l'espace. |
| Inviter ou modifier des collaborateurs | Ouvrez l'onglet **Collaborateurs** de l'espace. Certaines modifications des membres du projet peuvent nécessiter une demande. |
| Créer un lien externe | Le projet doit autoriser le partage externe et votre rôle sur l'espace doit permettre cette action. |
| Créer des identifiants pour un outil externe | L'accès aux outils externes doit être activé pour le projet et disponible pour votre compte. |
| Versions précédentes d'un fichier | Le stockage sous-jacent doit conserver des versions pour cet espace et vous devez avoir le droit de les lire. |
| Activité ou journaux d'accès | L'historique disponible dépend de votre rôle Portal et des fonctions activées pour le projet. |

## Que faire

1. Vérifiez le projet affiché dans l'en-tête de Portal.
2. Rouvrez l'espace depuis **Espaces** afin de repartir de son état et de ses droits actuels.
3. Si une action est désactivée, lisez le message affiché à proximité avant de réessayer.
4. Si l'accès reste incorrect, ouvrez [Demandes](../help-requests.md) ou contactez
   votre administrateur en indiquant le projet, l'espace, l'action et le message d'erreur exact.

N'essayez pas d'utiliser un autre workspace pour contourner une permission Portal
manquante. Portal Manager est un rôle de Portal et n'implique pas un accès au
workspace Manager.
