# Glossaire Portal

| Terme | Signification dans Portal |
|---|---|
| Projet | Zone Portal à laquelle vous avez été ajouté. Sélectionnez le projet avant de travailler avec ses espaces. |
| Espace de stockage | Zone de stockage présentée par Portal pour vos fichiers et la collaboration. |
| Portal User | Membre du projet qui travaille avec les espaces qui lui sont accessibles. |
| Portal Manager | Rôle du projet avec des responsabilités Portal supplémentaires et un accès aux espaces du projet. Il est indépendant du workspace Manager. |
| Propriétaire | Personne responsable d'un espace privé. |
| Lecteur | Collaborateur qui peut lire et télécharger le contenu d'un espace partagé. |
| Éditeur | Collaborateur qui peut également ajouter, organiser et supprimer du contenu selon les règles de l'espace. |
| Espace d'équipe | Espace partagé selon les règles de collaboration du projet. |
| Espace privé | Espace dont le contenu reste limité à son propriétaire et aux Portal Managers. |
| Lien externe | Lien à durée limitée ou contrôlé par une politique permettant de partager un fichier hors de l'appartenance normale au projet, lorsque cette fonction est activée. |
| Outil externe | Application compatible S3 configurée avec l'endpoint et les identifiants fournis par Portal lorsque cette fonction est activée. |
| Demande | Demande Portal envoyée lorsqu'un administrateur doit approuver ou réaliser une modification pour vous. |
| Espace archivé | Espace conservé pour une restauration ultérieure mais indisponible pour le travail normal sur les fichiers tant qu'il est archivé. |
