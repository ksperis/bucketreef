# Versions précédentes d'un fichier

Utilisez cette page pour récupérer une ancienne copie d'un fichier ou restaurer
un fichier supprimé d'un espace de stockage Portal.

## Consulter l'historique

1. Ouvrez le projet et l'espace de stockage.
2. Recherchez le fichier puis ouvrez **Historique** ou **Versions** dans ses détails.
3. Consultez les dates et les versions disponibles. Un fichier supprimé peut
   afficher un marqueur de suppression alors que du contenu plus ancien est
   toujours conservé.
4. Téléchargez une ancienne version si vous avez seulement besoin d'une copie,
   ou choisissez **Restaurer** pour la rendre à nouveau courante.
5. Revenez dans **Fichiers** et vérifiez que le fichier attendu est visible.

Lorsqu'elle est disponible, l'option **Afficher les fichiers supprimés** aide à
retrouver les fichiers actuellement supprimés mais dont l'historique peut encore
être restauré.

L'onglet **Historique** regroupe la version courante et les versions précédentes
et propose l'action de restauration directement sur la version choisie.

## Si l'historique n'est pas disponible

Un espace de stockage ne peut afficher que les versions conservées par le
stockage sous-jacent et que vos droits Portal vous permettent de lire. Si aucune
action d'historique n'est disponible alors que le fichier devrait être
restaurable, contactez l'administrateur du projet.

Restaurer une version n'efface pas l'historique plus ancien. Supprimer une
version historique est destructif : ne le faites que lorsque cette version
n'est réellement plus nécessaire.
