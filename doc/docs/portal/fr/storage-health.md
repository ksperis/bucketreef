# État du stockage

Utilisez cette page pour savoir s'il reste de la place pour de nouveaux
fichiers, quels espaces grandissent, comment les fichiers entrent et sortent du
stockage et, lorsque l'information est disponible, quel peut être le coût du mois.

## Avant de commencer

- Sélectionnez le bon projet.
- La collecte de l'utilisation, des quotas, du trafic ou des coûts doit être
  activée sur la plateforme pour que l'onglet correspondant apparaisse.
- Certaines métriques peuvent être indisponibles alors que l'accès aux fichiers fonctionne normalement.

## Ce que Portal peut afficher

| Indicateur | Signification |
|---|---|
| Vue d'ensemble | Stockage utilisé, place restante, nombre de fichiers et espaces visibles pour le projet sélectionné. |
| Par espace | Stockage et nombre de fichiers pour les espaces auxquels vous avez accès. |
| Types de fichiers | Répartition facultative des fichiers visibles par type, taille et classe de stockage. |
| Tendances | Mesures enregistrées montrant l'évolution du stockage et du nombre de fichiers. |
| Imports et téléchargements | Mouvements de fichiers et activité lorsque la collecte du trafic est disponible. |
| Coûts | Estimation mensuelle facultative pour le stockage et les transferts. |
| Autre | Stockage anonyme utilisé ailleurs dans le projet. Ce n'est pas un espace que vous pouvez ouvrir et aucun nom ou identifiant masqué n'est révélé. |
| Alertes | Avertissements dédupliqués, par exemple quota proche de la limite, lien public ou endpoint dégradé. |

Les détails du trafic ne sont affichés que pour les espaces auxquels vous avez accès.
Le tableau de bord peut conserver des totaux globaux afin de montrer la pression
sur le quota, sans exposer le nom des espaces privés des autres utilisateurs.

## Résultat attendu

Vous pouvez déterminer s'il reste de la place dans le projet, quels espaces
méritent votre attention, si les transferts paraissent normaux et si des données
de coût sont disponibles.

## Si une métrique est indisponible

Une métrique absente ne signifie pas forcément que l'espace est en panne.
L'accès aux fichiers peut continuer alors que les données d'utilisation, de
trafic ou de coût sont temporairement indisponibles. Si l'absence persiste,
indiquez à votre administrateur le projet, l'onglet concerné et l'heure.
