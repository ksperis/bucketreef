# Paramètres Portal

Utilisez **Portal > Paramètres** pour consulter les paramètres appliqués au
projet sélectionné. Les Portal Managers peuvent les modifier uniquement lorsque
cette responsabilité leur a été déléguée.

## Consulter les paramètres du projet

1. Ouvrez **Portal > Paramètres**.
2. Vérifiez le projet sélectionné.
3. Consultez les valeurs appliquées et leur origine : valeur par défaut de la
   plateforme ou choix spécifique au projet.
4. Si la page est modifiable, changez uniquement les options dont vous êtes
   responsable puis choisissez **Enregistrer les modifications**.
5. Utilisez **Annuler** pour abandonner un brouillon ou **Restaurer les valeurs
   de la plateforme** lorsque le projet doit à nouveau suivre les valeurs globales.

Les changements restent dans le formulaire jusqu'à leur enregistrement. Quitter
la page, changer de projet ou fermer une fenêtre modifiée demande confirmation
afin d'éviter de perdre un brouillon par erreur.

## Paramètres possibles

Selon le projet, les paramètres peuvent contrôler notamment :

- la possibilité pour les Portal Users de créer des liens externes ou des accès pour outils externes ;
- le comportement par défaut des nouveaux espaces de stockage ;
- la conservation de l'historique des fichiers ;
- les origines navigateur autorisées nécessaires aux workflows de fichiers.

Modifier une valeur par défaut pour les nouveaux espaces ne réécrit pas les
espaces existants. Modifiez les paramètres de l'espace concerné si un espace
déjà créé doit changer.

## Rôles et approbations

Chaque membre du projet peut consulter les paramètres effectifs. Un Portal
Manager ne peut les modifier que si l'administrateur lui a délégué cette
responsabilité. Sinon, il peut demander une modification éligible via
[Demandes](help-requests.md).

Les rôles Portal sont indépendants du workspace Manager. Disposer d'un accès
Manager ne change pas les droits de modification de cette page Portal.

## Si la page est en lecture seule

Cela signifie généralement que l'administrateur du projet conserve la
responsabilité du paramètre. Utilisez **Demandes** lorsque Portal le propose ou
contactez l'administrateur en indiquant le projet et le changement souhaité.
