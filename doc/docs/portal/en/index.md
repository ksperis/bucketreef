# Portal Guide

Portal is the self-service workspace for people who work with **Storage
Spaces**, files, collaborators, usage, and project-level help without needing
to understand storage administration.

## Start here

1. Open `/portal` and select the project you were given access to.
2. Open or create a [Storage Space](spaces/index.md), according to your role.
3. Use [Files](files/index.md) to browse, upload, download, preview, and recover
   files.
4. Use [Collaboration](collaboration.md) to understand access and sharing.
5. Use [Storage health](storage-health.md) to understand available capacity and
   alerts.
6. Use [Help requests](help-requests.md) when an administrator must change
   membership or storage limits.

## Roles

- **Portal User** works with the Storage Spaces granted to them and can manage
  content according to the role on each space.
- **Portal Manager** has the additional Portal project responsibilities
  documented in this guide.

Portal Manager is a Portal role. It is independent from the Manager workspace
and does not grant `/manager` access.

## External tools

When enabled, [External tools](external-tools.md) lets you create credentials
for an S3 client. The page explains only the endpoint and credential information
needed by the user; platform credential management remains an administrator
responsibility.
