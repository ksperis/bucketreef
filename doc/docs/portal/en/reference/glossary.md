# Portal Glossary

| Term | Meaning in Portal |
|---|---|
| Project | The Portal area you have been added to. Select the project before working with its spaces. |
| Storage Space | A storage area presented by Portal for your files and collaboration. |
| Portal User | Project member who works with the spaces granted to them. |
| Portal Manager | Project role with additional Portal responsibilities and access to project spaces. It is unrelated to the Manager workspace. |
| Owner | Person responsible for a private Storage Space. |
| Viewer | Collaborator who can read and download content from a shared space. |
| Editor | Collaborator who can also add, organize, and delete content according to the space rules. |
| Team space | Space shared according to the project's collaboration rules. |
| Private space | Space whose content stays limited to its owner and Portal Managers. |
| External link | Time-limited or policy-controlled link used to share a file outside normal project membership when enabled. |
| External tool | S3-compatible application configured with Portal-provided endpoint and credentials when that function is enabled. |
| Help request | Portal request sent when an administrator must approve or perform a change for you. |
| Archived space | Space kept for later restoration but unavailable for normal file work while archived. |
