# Portal Use Cases

## Store project files

Open the project, choose a Storage Space, and use its Files view to upload,
organize, preview, and download content.

## Work with a team

Use a team or selected-people space and manage collaborators according to your
Portal role. When a project-membership change needs administrator approval,
Portal turns the action into a Help request.

## Recover an earlier file

When version history is available, open the file's previous versions and restore
or download the required state.

## Share outside the project

When your project permits external sharing, create or review external links from
the relevant file/space workflow. Existing links remain visible so authorized
users can revoke them.

## Use another application

When external-tool access is enabled, use the Portal-provided S3 endpoint and
credentials to configure the approved client. Keep the secret in that client;
do not share it with collaborators.

## Monitor storage health

Use Storage health to understand the capacity and alerts exposed to your project.
If a limit must change, follow the project's support or Help request workflow.
