# Common Portal Tasks

| What you want to do | Go to |
|---|---|
| Open a Storage Space | [Spaces](../spaces/index.md) |
| Upload, download, preview, rename, move, or delete a file | [Files](../files/index.md) |
| Recover or inspect an earlier file version | [Previous versions](../files/versions.md) |
| Share a space with project members | [Collaboration](../collaboration.md) |
| Review or revoke external file links | [Collaboration](../collaboration.md) |
| Connect an external S3 tool | [External tools](../external-tools.md) |
| Check capacity or usage alerts | [Storage health](../storage-health.md) |
| Review project activity | [Activity](../activity.md) |
| Ask for membership or another administrative change | [Help requests](../help-requests.md) |
| Change Portal project preferences available to you | [Settings](../settings.md) |

If an action is missing or read-only, start with [Feature availability](../help/feature-availability.md).
