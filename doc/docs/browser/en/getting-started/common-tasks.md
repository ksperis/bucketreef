# Common Browser Tasks

| Task | Go to | Check first |
|---|---|---|
| Browse a bucket or prefix | [Object operations](../objects/operations.md) | Correct context and bucket are selected. |
| Upload files | [Object operations](../objects/operations.md) | You have write permission; direct upload may require compatible CORS. |
| Download or preview an object | [Object operations](../objects/operations.md) | You have read permission. |
| Copy or move objects | [Object operations](../objects/operations.md) | Destination context/path and Advanced-profile requirements are understood. |
| Download a mixed selection as ZIP | [Object operations](../objects/operations.md) | Review selection scope and ZIP limits. |
| Save a path as a favorite | [Object operations](../objects/operations.md) | The location is available in standalone Browser. |
| Inspect or restore a previous version | [Object versions](../objects/versions.md) | Bucket versioning and version-list permission are available. |
| Delete objects | [Safe operations](../reference/safe-operations.md) | Exact keys and recovery expectations are understood. |
| Diagnose a failed transfer | [Troubleshooting](../help/troubleshooting.md) | Open the current operation details first. |
